# Контекст: улучшение работы с личным составом на планшете

## Запрос
Улучшить удобство, скорость поиска человека и общее взаимодействие, с приоритетом планшета.

## Желаемый результат
Оперативный интерфейс, где частые действия с человеком выполняются быстрее и без лишней навигации.

## Факты из кода
- Основной пользовательский контур: Обзор, Все взвода, отдельные взвода, Группы, Задачи.
- Поиск по ФИО, званию и номеру призыва уже есть внутри списков личного состава, но не является постоянным глобальным действием.
- На ширине до 900 px боковая навигация заменяется верхней горизонтальной лентой и меню.
- Карточки человека открывают панель смены места; в общем списке есть быстрые кнопки места.
- Часть быстрых кнопок имеет размер 34–40 px, что тесно для регулярной планшетной работы.

## Ограничения
- Сохранить текущую тему и русские UTF-8 подписи.
- Использовать существующие общие кастомные контролы.
- Не менять бизнес-логику и хранение без отдельного обоснования.

## Неизвестно
- Главный рабочий сценарий оператора.
- Ориентация/типичный размер планшета.
- Должен ли первый этап быть только UX-планом или сразу реализацией.
