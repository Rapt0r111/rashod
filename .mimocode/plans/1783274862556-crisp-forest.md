# План реализации функции "Уборщики"

## Краткое описание
Система ротации уборщиков с возможностью:
- Ручного назначения/смены уборщиков
- Исключения определённых людей из ротации
- Хранения истории назначений
- Настройки количества уборщиков и разрешённых взводов
- Отдельного раздела в UI

---

## Архитектурные решения

### 1. База данных (3 новые таблицы)

**`cleanerAssignments`** — назначения уборщиков:
| Поле | Тип | Описание |
|------|-----|----------|
| id | text PK | UUID |
| personId | text | ID назначенного |
| assignedDate | text | Дата (YYYY-MM-DD) |
| assignedBy | text | "system" или "manual" |
| createdAt | integer | Timestamp |

**`cleanerExclusions`** — исключённые из ротации:
| Поле | Тип | Описание |
|------|-----|----------|
| id | text PK | UUID |
| personId | text | ID исключённого |
| dayOfWeek | integer | День недели (0-6, null = всегда) |
| createdAt | integer | Timestamp |

**`cleanerSettings`** — настройки (одна строка):
| Поле | Тип | Описание |
|------|-----|----------|
| id | text PK | "default" |
| enabledPlatoons | text | JSON массив ID взводов |
| cleanersPerDay | integer | Кол-во уборщиков (по умолчанию 1) |
| autoRotate | boolean | Авто-ротация (по умолчанию true) |
| activeDays | text | JSON массив активных дней (0-6, по умолчанию все) |

### 2. Алгоритм ротации (по приоритету)

```
1. Получить кандидатов:
   - Все люди из разрешённых взводов
   - Исключить из cleanerExclusions
   
2. Рассчитать приоритет для каждого:
   - Для каждого кандидата найти дату последнего назначения
   - Приоритет = кол-во дней с последнего назначения
   - Если ни разу не был уборщиком → максимальный приоритет (999)
   
3. Отсортировать по убыванию приоритета:
   - Кто дольше всех не был уборщиком — первый в списке
   
4. Выбрать первых N кандидатов (N = cleanersPerDay):
   - Если несколько людей имеют одинаковый приоритет — случайный выбор среди них
   
5. Записать в cleanerAssignments
```

### 3. API Endpoints

| Метод | Путь | Описание |
|-------|------|----------|
| GET | `/api/cleaners` | Снапшот: сегодняшние уборщики, настройки, исключения |
| POST | `/api/cleaners/assign` | Назначить уборщика вручную |
| POST | `/api/cleaners/rotate` | Запустить ротацию (сменить уборщиков) |
| POST | `/api/cleaners/exclude` | Исключить из ротации |
| DELETE | `/api/cleaners/exclude` | Вернуть в ротацию |
| PUT | `/api/cleaners/settings` | Обновить настройки |
| GET | `/api/cleaners/history` | История назначений |
